# Front-End Web Development — Practice Work

This repository contains the work I completed for the **Aesthetix Edu-Tech five-day front-end training programme** at **KMEA Engineering College**.

I used HTML, CSS and JavaScript to make a few pages and small exercises. The code is beginner-level and I may change it as I learn more.

## Programme details

- Training: Aesthetix Edu-Tech
- College: KMEA Engineering College
- Duration: 5 days (30 hours, as stated in the programme)
- Main topics: HTML, CSS and JavaScript

## What is in the repository?

| File | What it does |
| --- | --- |
| `index.html` | My profile and links to the other pages |
| `resume.html` | Resume-style HTML and CSS exercise |
| `calculator.html` | Calculator and sample form validation |
| `todo.html` | To-do list with add, complete and delete options |
| `styles.css` | Styles shared by the pages |
| `script.js` | Navigation, calculator, form and to-do JavaScript |
| `my.jpeg` | Profile photo used on the home page |

## Work by day

**Day 1 — HTML**

Practised the basic HTML page structure, headings, paragraphs, links, images, lists, tables and semantic elements. I used these for the profile and resume pages.

**Day 2 — CSS**

Added an external stylesheet and tried different colours, fonts, spacing, borders and backgrounds. The resume page also has a few cards to practise styling.

**Day 3 — Layout and responsive pages**

Used Flexbox, Grid and media queries. The navigation changes to a menu button on smaller screens.

**Day 4 — JavaScript**

Made a calculator and a form that checks the name, email and message fields. The form is only a demo; it does not submit or store the details.

**Day 5 — Mini project**

Made the to-do list. Tasks can be added, marked complete and deleted. The browser's local storage is used to keep the list after refreshing the page.

## Run it

There is no build step or package to install.

1. Download or clone the repository.
2. Open the folder in VS Code or another editor.
3. Open `index.html` in a browser.
4. Use the menu to open the other pages.

- Open each page and use its navigation links.
- Make the browser narrow and check the menu.
- Try `12 + 8` and `(4 + 6) * 2` in the calculator.

- Submit the form with empty values, then try valid values.
- Add a task, mark it complete, refresh the page and check that it remains.
