# KMEA Web Development Add-on Course

A five-day learning project created during the web development add-on course at **KMEA Engineering College**.

This repository records the progress of a small personal profile website as new concepts are introduced during the course. It is a learning exercise, not a claim of advanced web-development experience.

## Live Website

[View the website](https://muneeb-pt.github.io/add-on_class_profile/)

## Technologies

- **HTML** — page structure and content
- **CSS** — layout, styling, and responsive design
- **JavaScript** — to be practised as it is covered during the course

## Running Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Learning Goal

Use the five days to understand the fundamentals, practise each concept independently, and gradually improve the same website. The priority is learning and writing the code—not adding tools or features that have not been covered yet.
